# FirmoQuest

Simulator economic educativ: construiește o fermă sau condu o companie IT, gestionează resursele și dezvoltă afacerea.

Toate cele trei dificultăți sunt gratuite doar în demo-ul pentru hackathon.

## Instalare

- **Windows:** [Descarcă EXE-ul](https://github.com/Chuvachox/FirmoQuest/releases/download/v0.5.0-beta.1/FirmoQuest-Windows-x64.exe) și deschide-l.
- **Android:** [Descarcă APK-ul](https://github.com/Chuvachox/FirmoQuest/releases/download/v0.5.0-beta.1/FirmoQuest-Android.apk), instalează-l și joacă în peisaj.

Componentele necesare sunt incluse. Nu trebuie să instalezi separat Godot sau .NET.
